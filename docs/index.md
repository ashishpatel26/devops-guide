# Welcome to the DevOps Master Guide

This guide is designed to help you master DevOps tools and practices, starting from the absolute basics. Whether you are on Windows, macOS, or Linux, we have you covered.

## What's Inside?

* **Learning Path**: A step-by-step roadmap to becoming a DevOps Engineer.
* **Installation Guides**: Detailed instructions to set up your environment on any OS.
* **Tools & Commands**: Scenario-based cheat sheets and guides for essential tools like Git, Docker, Kubernetes, and more.

## Getting Started

If you are new to DevOps, start with the [Learning Path](learning-path.md) to understand the journey ahead. Then, visit the [Installation Guides](installation/index.md) to prepare your computer.
